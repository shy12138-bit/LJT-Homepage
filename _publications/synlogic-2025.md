## SynLogic: Synthesizing Verifiable Reasoning Data at Scale for Learning Logical Reasoning and Beyond

**First author:** Junteng Liu

**Co-authors:** Yuanxiang Fan, Zhuo Jiang, Han Ding, Yongyi Hu, Chi Zhang, Yiqi Shi, Shitong Weng, Aili Chen, Shiqi Chen, Yunan Huang, Mozhi Zhang, Pengyu Zhao, Junjie Yan, Junxian He

**Venue:** Arxiv (2025)

This paper proposes a method for synthesizing verifiable reasoning data at scale for learning logical reasoning in large language models. It is Junteng Liu's first-author publication (2025). The work has a GitHub code repository available.

**Keywords:** LLM Reasoning, Logical Reasoning, Reinforcement Learning, Verifiable Data Synthesis
