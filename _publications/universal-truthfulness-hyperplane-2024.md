## On the Universal Truthfulness Hyperplane Inside LLMs

**First author:** Junteng Liu

**Co-authors:** Shiqi Chen, Yu Cheng, Junxian He

**Venue:** EMNLP 2024 (Conference on Empirical Methods in Natural Language Processing)

This paper explores the universal truthfulness hyperplane inside large language models, providing an inner representation perspective on LLM truthfulness and interpretability. It is Junteng Liu's first-author publication, published at EMNLP 2024. The work has a GitHub code repository available: **Universal_Truthfulness_Hyperplane**.

**Keywords:** LLM Truthfulness, Interpretability, Truthfulness Hyperplane, EMNLP
